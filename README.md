# Rhythm Cycling

Tools for building rhythm cycling class playlists: suggest songs for a class
theme and tempo range, review them, then turn the picks into a Spotify playlist.

## Data sources

- BPM, key and related song data is provided by
  [GetSongBPM](https://getsongbpm.com).
- Playlists are created through the Spotify Web API.
